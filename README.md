AI-модератор социальных сетей

Как запустить на Windows

1. Установите Python 3.10–3.12.
2. Откройте PowerShell в папке проекта.
3. Выполните команды:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Если PowerShell запрещает активацию, используйте команды без активации:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Для скачивания и конвертации некоторых видео нужен **FFmpeg**, доступный
через PATH. Для части роликов YouTube также может понадобиться Node.js или Deno.
Модуль `parser.py` сообщит о соответствующей ошибке.

## Опционально: Gemini

Для анализа изображений из видео нужен API-ключ Google Gemini.
Перед запуском в PowerShell:

```powershell
$env:GEMINI_API_KEY="ваш_ключ"
streamlit run app.py
```

Не записывайте настоящий ключ прямо в `vision_check.py` и не публикуйте его.
В интерфейсе отдельно разрешите передачу кадров в Gemini. Без разрешения
кадры не отправляются во внешний сервис.

## Проверки

- **Ссылка:** YouTube, TikTok или Instagram (публичные публикации). Telegram пока не поддерживается.
- **Текст:** модель ruBERT оценивает токсичность, а отдельный словарь ищет
  характерные слова и фразы. При первом запуске модель скачивается из Hugging Face.
- **Видео → текст:** Whisper распознаёт речь, EasyOCR — текст на 1–5 кадрах.
  EasyOCR использует русский и английский языки; часть казахских букв может
  распознаваться неточно. Для речи поддерживаются языки Whisper.
- **Изображения:** до 8 кадров отправляются в Gemini, только при согласии.
- **Антифрод:** объяснимые правила для адресов ссылок и свойств аккаунта.
  Это **не** полноценная модель определения мошенничества.

Итоговый результат — **индекс риска от 0 до 100**, равный максимальному
доступному индексу модулей. Это не статистическая вероятность.
Порог 40 означает рекомендацию ручной проверки, 70 — высокий риск.
Автоматическая блокировка не выполняется.

Если библиотека, NLP-модель или Gemini недоступны, интерфейс показывает
ошибку или неполную проверку. **Заглушки с выдуманными 90% удалены**.
Сохранённые в сессии результаты не содержат самого видео; временные
видеофайлы удаляются после завершения проверки.

## Проверка без интернета

```powershell
python -m unittest discover -s tests -v
```

Эти тесты проверяют функции на простых примерах, но не заменяют испытания
нейросети на реальном наборе данных. Для честной оценки точности нужны
размеченные примеры, precision/recall и матрица ошибок.
